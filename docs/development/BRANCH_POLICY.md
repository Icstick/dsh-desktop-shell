# Branch and PR Policy

`main` 使用 required PR、required checks、required review、linear/squash history，禁止 direct push。短分支命名：`feat/`、`fix/`、`docs/`、`compat/`、`security/`、`chore/`。

只有维护已发布 minor 时创建 `release/X.Y`。Protocol、Supervisor/IPC、安全和 release 变更采用更高 review 门禁，详见 CONTRIBUTING。

M0 无 GitHub 远端，因此本文件描述目标治理；远端配置后将 ruleset evidence 链接到 tracking review。
