# Clean-room Policy

## 允许

- 研究公开文档、API、行为、需求、故障模式和架构模式。
- 通过独立规范、公开平台 API 和本项目测试重新实现。
- 记录 architecture-reference-only 来源。

## 未经审计禁止

- 复制或改写受限第三方源代码。
- 搬运图标、截图、品牌资产、文案或大段注释。
- 将“MIT 文件存在”当作忽略附加条款的依据。
- 复制 build/patch/recovery scripts 后仅改名。

## 记录

每个来源包含 URL、revision、license、additional terms、用途、code_copied、assets_copied、reviewer、decision。实现 PR 必须声明 provenance。
