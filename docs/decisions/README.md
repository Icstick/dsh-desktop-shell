# Architecture Decision Records

ADR 是 ownership、public contract、状态机、transport、trust boundary、技术栈和许可决策的原因真源。

## 状态

`proposed -> accepted -> superseded`；已接受 ADR 不原地改写结论。需要改变决策时创建新 ADR，并在旧文档中记录 superseded-by。
