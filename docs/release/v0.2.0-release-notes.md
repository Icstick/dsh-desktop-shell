# DSH Desktop Shell v0.2.0

> DeepSeek 角色主题 + 浏览器多标签工作台。在 v0.1.0（Stable Candidate）之上的两个 feature 版本：
> 全新蓝白海洋视觉体系（DeepSeek 鲸鱼娘主题）与浏览器多会话标签（文档标题 / 多开互不顶替）。

## 本版本新增

### 🎨 DeepSeek 角色视觉主题（WI-M8-DEEPSEEK-UI）

- 蓝白海洋配色（navy ink / porcelain / lake blue / restrained gold）+ 深蓝导航 rail（角色头像 + 字标）
- 每页横幅角色插画按页面职责映射：欢迎水面 / 设置工作坊 / 浏览器探索台 / 通知信使角 / 用量账本 / 运行时观象台
- 插画纯装饰（不挡内容、沉浸页自动隐藏、渐变遮罩保可读）；双语页面描述；本地预览 fixture（不连后端）
- 主题插画素材来自 ZipZipPipe（上善无形）DeepSeek 角色设定，**CC BY-NC-SA 4.0**（非商业授权），完整出处见 assets/ATTRIBUTION.md

### 📑 浏览器多会话标签（WI-M9-BROWSER-TABS）

- 标签栏列出全部实时会话，**自动显示网页标题**（title_changed 事件流）
- **打开网址永不顶替当前页面**：空标签原地填充，有内容的标签旁自动开新会话窗口——agent 驱动的页面与你的浏览互不干扰
- 新建 / 关闭 / 切换标签；Shell 重启后孤儿会话静默清理（不弹窗、无死标签）
- 配套修复：daemon 断连释放会话归属（重连可管理自己的会话）、browser.close 契约修正（标签关闭联动窗口关闭）

### 🔧 稳定性与工程

- 暗色主题细节打磨（质感层级 / 激活指示 / 状态色）
- 终端页无限伸长根因修复（workspace 固定 100vh）
- ACL 清单全量对齐（check:acl 40 命令绿——remove_environment 此前被清单漏登记，删除环境功能实际被拒）
- 插画素材 webp 打包（安装体积 19.4MB → 1.3MB，原始 PNG 不入安装包）
- 发布链路启用 SLSA build provenance（attestation，repo 已公开）

## 安装与运行

- Windows：运行 setup exe（自签证书首次运行需「更多信息 → 仍要运行」）
- macOS：无签名 dmg（首次打开需右键 → 打开）
- Linux：deb 包（依赖 libwebkit2gtk-4.1/gtk3/appindicator）
