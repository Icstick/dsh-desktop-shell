# DSH Desktop Shell v0.1.0

> 首个公开版本（Stable Candidate）。Tauri 2 + React + Rust 的 DeepSeek Harness 桌面壳：
> Managed/Attached 运行时管理、DSH Web Surface（WebView2 权限拦截）、Workbench 终端（ConPTY / openpty）、
> 配置向导、多 profile 切换、daemon 常驻 + envelope 协议、三平台 CI 与发布链路。

## 这是什么

dsh-desktop-shell 是一个把 DeepSeek Harness 装进桌面的壳：启动/守护 DSH 进程、
把 DSH Web UI 挂载为原生窗口、提供终端与浏览器能力、跨会话保持 daemon 存活。
所有 agent 原生动作先过 DSH tool/policy，再进 Capability Broker（分权不变量）。

## 本版本包含

- **M0-M5**：架构基线、Shell MVP、Reliable Runtime（supervisor/restart/daemon）、Workbench 终端、
  Notification/Usage、Browser Surface、dsh-std adapter 基线
- **M6 daemon**：常驻 daemon + envelope 协议（Hello/Agreement/Invocation/Result/Event）、
  凭证系统、PTY/browser/runtime 能力、scheduler wake、i18n 中英切换
- **M7**：六步配置向导、多 profile 管理（B1 激活/切换）、CDP live QA
- **M8 Stable Candidate**：
  - 三平台 CI 矩阵（windows/macos/ubuntu）+ 双 live QA 全绿
  - Unix PTY（openpty，macOS 双根因修复：poll 假阳性 O_NONBLOCK + SIGKILL 后 waitpid 有界 reap）
  - browser 非 Windows 降级（wry 默认 webview，能力标注 degraded）
  - cargo-deny 依赖门禁 + SBOM（Rust cyclonedx + pnpm lockfile 转换器）
  - Windows 自签（DV 级）签名路径 + SmartScreen 说明

## 安装与运行

- Windows：运行 setup exe（自签证书首次运行需「更多信息 → 仍要运行」）
- macOS：无签名 dmg（首次打开需右键 → 打开；Developer ID 待账号就绪）
- Linux：deb 包（依赖 libwebkit2gtk-4.1/gtk3/appindicator）

## 安全与边界

- Surface/Automation 分权；所有 native 动作经 DSH tool/policy + Capability Broker
- 终端/浏览器 session 由 daemon 权威管理（opaque id，profile 隔离）
- 自签证书不加入 Trusted Root；信任由首次运行时显式授予
- 依赖审计：16 个 unmaintained advisory 已记录（均为 tauri Linux 栈传递依赖，无安全漏洞）

## 校验

- 三平台 CI 全绿（test + live-qa + cargo-deny）
- REVIEW-M8 双轴评审（standards + spec）approve-with-comments，major 修复闭环
- 真实 DSH token 验证（authenticated root + 43 位 launchToken 契约 + 真实 cookie 200）
- 产物校验和与本 release 的 SBOM/attestation 一致

## 已知限制

- 非 Windows browser 无权限拦截（degraded，tauri 导航门兜底）
- macOS 无签名（等待 Developer ID）
- AppImage 未做（deb 优先）
- B2 并发多 profile 规划在 M9/M10
